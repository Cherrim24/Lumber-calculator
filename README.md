# Lumber-calculator
Веб-приложение для проектирования сруба: 2D-план стен + 3D-визуализация. Один HTML-файл, без сборки.

Запуск
Открыть index.html в браузере (нужен интернет для Three.js с CDN).

Интерфейс
Левая панель — 2D-план этажа.
Правая панель — 3D-вид (OrbitControls: вращение, зум, панорама).
Верхняя панель — инструменты, этажи, материалы.

Инструменты (toolbar)
Стена — наружная стена. Клик = точка, клик у первой точки = замкнуть контур. ПКМ = отменить шаг.
Внутр. стена — перегородка: клик на стене → протянуть к другой стене → клик.
Удалить — клик по стене удаляет её.
Выделить — клик/рамка для выделения, перетаскивание перемещает стены, ПКМ/Del — удалить.
Дверь / Окно — клик по стене добавляет проём.
+ Этаж — добавить следующий этаж.
Высота — высота текущего этажа (2–4 м).
Крыша — открыть панель настройки крыши.
Палитра — цвет материала стен.

Горячие клавиши
Shift — свободный угол (без привязки к 15°).
Esc — отменить текущую стену / снять выделение.
Delete — удалить выделенные стены.
ПКМ — отмена шага, удаление выделения (с подтверждением) или панорама.
Колесо — зум 2D.
Двойной клик — завершить цепочку / сбросить камеру.

Привязки (2D)
Сетка 0.25 м и радиус привязки 0.5 м.
К вершинам и сторонам существующих стен.
Автоматическое выравнивание по осям дома (работает и для «повёрнутых» домов).
Пересечение под прямым углом от опорной вершины.
Угол с шагом 15° по полному кругу, привязан к осям дома.
Этажи
Список этажей — вкладки поверх 2D-плана.
Перекрытие между этажами строится автоматически.

У каждого этажа свои стены и своя высота.

Крыша
Два режима: основная (по самому большому замкнутому контуру) и пристройки (по остальным контурам).
Типы: двускатная, вальмовая, односкатная, плоская.
Параметры: уклон (5–60°) и свес (0–1.5 м).
Контуры находятся автоматически как замкнутые связные компоненты наружных стен.
Ориентация крыши определяется методом главных осей (PCA) по направлениям стен.

3D
Стены строятся с учётом толщины и проёмов (двери, окна).
Материалы стен, перегородок, перекрытий и крыши.
Освещение: ambient + directional (тени) + hemisphere.
Камера вращается через OrbitControls.
Внутренние данные (объект PROJ)
floors[] — массив этажей { walls, yBase, height }.
walls[] — стены этажа { x1,z1,x2,z2, type, gaps[] }.
roof, roofAnnex — параметры крыш { type, slope, over }.
mat, matRoof — цвета материалов.
tool, selFloor — текущий инструмент и этаж.

Особенности
Полностью клиентское приложение: ничего не отправляется на сервер.
Один файл — легко встроить или открыть локально.
Снап-система адаптирована под диагональные и повёрнутые планы.
Работает на десктопе с мышью (touch только для панорамирования 3D).
